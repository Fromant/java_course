# Использование: 
1. Кодирование: `java Huffman -c [input] [output]`
2. Декодирование: `java Huffman -d [input] [output]`

### Формат архивного файла, создаваемого программой Huffman:

1. Заголовок:
   - 4 байта: N — количество уникальных символов (int)
   - 8 байт: totalBits — общее количество закодированных битов (long)
   - N записей по 5 байт:
      * 1 байт: символ (byte)
      * 4 байта: частота (int)

2. Тело:
   - Закодированные биты, записанные плотно, без выравнивания.
